## v0.0.0 (May 23, 2026)

_Initial version of the project_

Where **project** means a search engine on the local file system.

### Core features:
- Crawls the file system and indexes text and image files 
- Text files can be queried by name, content or metadata
- Image files can be queried by dominant color
- Complex queries are supported based on a simple grammar
- Results are ranked to satisfy user needs
